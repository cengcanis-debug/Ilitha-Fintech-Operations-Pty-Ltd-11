# Security Policy - Ilitha Fintech Operations Pty Ltd

## Supported Versions

The following versions of the Ilitha Sentinel and associated sub-modules are actively supported with security patches:

| Version | Supported          |
| ------- | ------------------ |
| 2026.x  | :white_check_mark: |
| < 2026  | :x:                |

## Reporting a Vulnerability

If you identify a security vulnerability, data leak, or unauthorized access attempt on any Ilitha Fintech Operations platform (including SA Tender Assist, ZAtax, or Sifuna Ispan Mzantsi), please report it immediately:

1.  Do not open a public GitHub issue.
2.  Email your diagnostic report directly to the SCM Security Desk at **cengcanis@gmail.com**.
3.  Include steps to reproduce, affected endpoints, and if possible, a payload example.

We will acknowledge receipt of your report within 24 hours and provide an active status update on our resolution path.
